# Askezik

Веб-застосунок (PWA) для аскез: обіцянки собі на 7, 21, 30 днів або назавжди.
Ранкова обіцянка, вечірній підсумок зі щоденником, карта днів, віхи, картки для сторіс.
Мови: українська, русский, English. Дані зберігаються лише на пристрої.

## Як встановити на телефон
- iPhone (Safari): відкрий сайт → «Поділитися» → «На екран Додому».
- Android (Chrome): меню ⋮ → «Встановити застосунок».

## Як оновити
Завантаж нові файли з тими ж назвами (Add file → Upload files → Commit changes)
і зміни VERSION у sw.js (наприклад, askeza-v2).
